───────────────────────────────────────────────
RECOMMENDED TTS SETTINGS
───────────────────────────────────────────────

ENGINE PICKS (in order of quality)
  1. ElevenLabs — paid but most natural. Voice: "Bella" or "Aria".
  2. Microsoft Edge / Azure Neural TTS — free via edge-tts CLI.
     Best voices:  en-US-JennyNeural   ← warm, friendly female (recommended)
                   en-US-AriaNeural    ← modern, slightly more energetic
                   en-US-AndrewNeural  ← warm male
                   en-US-EmmaNeural    ← professional female
  3. Google Cloud TTS — Studio voices (en-US-Studio-O) are excellent.
  4. Amazon Polly — Neural voices: Joanna, Matthew, Ruth.

VOICE STYLE
  - Tone: warm, friendly, confident — like a helpful guide, not a salesperson
  - Speed: 95–100% (slightly under default for clarity)
  - Pitch: default
  - Emphasis: light stress on "Aircast", "anything", "Free, forever", "Install"

DELIVERY NOTES
  - "Meet Aircast." — slow, deliberate. Sets the tone.
  - "tap Search for TVs" — slightly playful, like demonstrating.
  - "Samsung, LG, Fire TV, Roku" — list cadence, small pause between each.
  - "Connected. In about two seconds." — satisfied, slight upward inflection on "Connected."
  - "watch movies, play games, present" — three-beat rhythm, each phrase same length feel.
  - "Free, forever." — strong emphasis on FOREVER.
  - "Install Aircast" — call to action, slightly punchier.
